DRTP_v2: Dense Residual Text Prior — CLIP 语义注入 FPN 门控融合
===========================================================================
DRTP_v2 在 FPN 输出后、Transformer Encoder 前，利用冻结的 CLIP ViT
patch tokens 通过可学习的门控机制逐层注入到 backbone 特征中。
目标是让检测器利用 CLIP 的预训练语义知识来增强文本区域的特征表达。


核心机制
────────

输入图片 (B, 3, H, W)
        │
        ├──────────────────────────────────────┐
        ▼                                      ▼
┌───────────────────────┐          ┌───────────────────────────┐
│  Backbone: ResNet-50  │          │  CLIP ViT-B-16 (Frozen)   │
│  → FPN 4 层           │          │  input: resize to 224×224 │
│                       │          │  output: patch_tokens      │
│  srcs[0] (B,256,H/8,W/8)        │  (B, 196, 768)             │
│  srcs[1] (B,256,H/16,W/16)      └───────────┬───────────────┘
│  srcs[2] (B,256,H/32,W/32)                  │
│  srcs[3] (B,256,H/64,W/64)     reshape → (B, 768, 14, 14)
└───────────┬───────────┐                    │
            │           │     ┌──────────────┴──────────────┐
            │           │     │  Per-Level Projection + Gate │
            │           │     │                              │
            │           │     │  V_l = Proj(clip_feat)        │
            │           │     │       ↓ resize→(H_l, W_l)     │
            │           │     │  G_l = sigmoid(               │
            │           │     │    GateNet([src_l ∥ V_l])     │
            │           │     │  )                            │
            │           │     │  src'_l = src_l + α_l·G_l·V_l │
            │           │     └──────────────┬───────────────┘
            │           │                    │
            ▼           ▼                    ▼
┌────────────────────────────────────────────────────────────┐
│  融合后的 srcs (文本语义已注入 FPN 特征)                      │
└────────────────────────────────────────────────────────────┘
        │
        ▼
┌────────────────────────────────────────────────────────────┐
│  Deformable Transformer Encoder + Decoder (纯 baseline)      │
└────────────────────────────────────────────────────────────┘
        │
        ▼  hs (6, B, 300, 16, 256)
predict heads: cls + coord


═══════════════════════════════════════════════════════════════════
DRTP_v2 内部流程
═══════════════════════════════════════════════════════════════════

输入: clip_images + srcs (4个FPN层)

  ┌──────────────────────────────────────────────────────┐
  │ [1] CLIP 预处理                                       │
  │  clip_tensor = resize_to_224(pad_to_square)          │
  └──────────────────────┬───────────────────────────────┘
                         │
                         ▼
  ┌──────────────────────────────────────────────────────┐
  │ [2] CLIP ViT 提取 (Frozen, no_grad)                   │
  │  patch_tokens (B, 196, 768)                          │
  │  → 最后一层 hidden state, 去掉 CLS token             │
  │  → reshape 为 (B, 768, 14, 14)                       │
  └──────────────────────┬───────────────────────────────┘
                         │
                         ▼
  ┌──────────────────────────────────────────────────────┐
  │ [3] Per-Level Gated Fusion (4层, 参数独立)            │
  │                                                      │
  │  for lvl in [0,1,2,3]:                               │
  │                                                      │
  │    [3a] CLIP 投影                                    │
  │     V = LayerNorm(Conv1×1(768→256)(clip_2d))         │
  │     V = F.interpolate(V, size=(H_l, W_l))            │
  │                                                      │
  │    [3b] 门控计算                                     │
  │     G = sigmoid(                                     │
  │       GateNet(                                       │
  │         cat([LayerNorm(src_l), V], dim=1)            │
  │       )                                              │
  │     )                                                │
  │                                                      │
  │     GateNet 结构 (3层, kernel_size=1):               │
  │       Conv1×1(512→256) → ReLU                       │
  │       Conv1×1(256→64)  → ReLU                       │
  │       Conv1×1(64→1)                                 │
  │     → 输出 (B, 1, H_l, W_l) 逐像素标量门             │
  │                                                      │
  │    [3c] 残差融合                                     │
  │     src'_l = src_l + α_l · G · V                     │
  │     α_l ∈ R, init=0.5, 可学习标量                    │
  │                                                      │
  └──────────────────────────────────────────────────────┘
                         │
                         ▼
  输出: fused_srcs (4层, 形状同输入)


═══════════════════════════════════════════════════════════════════
门控融合的核心思想
═══════════════════════════════════════════════════════════════════

逐位置决策: "这个位置的 backbone 特征与 CLIP 语义特征是否一致？"

  backbone_feat(pixel)  vs  CLIP_feat(pixel)
       ↓                          ↓
  ┌─────────────────────────────────────┐
  │  GateNet( concat(两者) ) → [0, 1]  │
  └─────────────────────────────────────┘
              │
    ├─ 接近 1 → 两者一致 → CLIP 语义可靠 → 注入
    └─ 接近 0 → 两者不一致 → CLIP 语义不可靠 → 跳过

  α_l 负责全局调节每层注入的强度，GateNet 负责空间上的选择性。

  GateNet 的作用不是"判断这个位置是不是文本"，
  而是"判断 CLIP 在这个位置给出的信号是否值得信任"。
  这是一种 cross-modal consistency check。

  关键限制 (kernel_size=1):
    GateNet 对每个像素独立做决策，没有空间上下文。
    → 竖排文本区域: 单像素特征难以区分横/竖方向
    → 小文字区域: 单像素 CLIP 特征信噪比极低
    → 这是当前 DRTP_v2 对竖排/小文字失效的根源


═══════════════════════════════════════════════════════════════════
实验结果 (CTW1500, SEED=42)
═══════════════════════════════════════════════════════════════════

  实验                P        R        F1       
  ───────────────  ───────  ───────  ────────
  baseline (纯视觉)  90.77    85.64    88.13    
  DRTP_v2            89.85    86.64    88.22    ← R↑ P↓, 跷跷板

  DRTP_v2 相比 baseline:
    P: 90.77 → 89.85  (跌 0.92) 
    R: 85.64 → 86.64  (涨 1.00) 
    F1: 88.13 → 88.22  (涨 0.09)

  分析:
    CLIP 语义注入确实提升了小文字/弱文字的召回 (R+1.0)，
    但 GateNet (kernel_size=1) 无法精确区分文本/非文本方向，
    导致部分背景区域被激活 → P 跌了 0.92。

配置开关

  USE_CLIP: True
  CLIP_DENSE_FUSION: True
  CLIP_ACTIVE_LEVELS: [0,1,2,3]     # 哪几层注入 (通常只用 [0])
  CLIP_USE_GATE: True                # 是否使用 GateNet
  CLIP_LEARNABLE_ALPHA: True         # α 是否可学习
  CLIP_FIXED_ALPHA_VALUE: 0.5        # α 初始值
  CLIP_SHARED_PROJECTOR: False       # 是否共享投影层

═══════════════════════════════════════════════════════════════════
已知局限
═══════════════════════════════════════════════════════════════════

1. 竖排文字：
   GateNet kernel_size=1，无法感知局部文本方向。
   CLIP 特征以水平文本为主，对竖排区域的语义表征弱。
   → 竖排文字区域可能被错误地降低门控值 → Recall 不升反降。

2. 小文字：
   CLIP 14×14 patch 分辨率不足以捕获小文字 (<20px) 的语义。
   插值上采样后 CLIP 特征在小文字区域含大量背景噪声。
   GateNet 逐像素决策无法区分噪声。
   → 小文字区域注入的是噪声而非语义 → 特征恶化。

3. P-R 跷跷板：
   当前 R+1.0 以 P-0.92 为代价，净增益仅 F1+0.09。
   根源: kernel_size=1 的 GateNet 判别力不足。

4. 改进方向:
   → Factorized Strip Conv GateNet (1×3 + 3×1 方向解耦)
   → 坐标编码增强位置感知


═══════════════════════════════════════════════════════════════════
与其他模块的关系
═══════════════════════════════════════════════════════════════════

  DRTP_v2 与以下模块正交，可自由组合:
    TACT:  几何信号 (控制点坐标) → decoder 内部注入
    SCGR:  几何信号 (曲率修正)   → decoder 内部注入
    CMFE:  语义信号 (CLIP text)  → decoder 内部注入
    MM-P3: 文本原型调制           → DRTP_v2 的 gate 上加 text modulation

  DRTP_v2 是 encoder 前的语义注入，
  其他模块是 decoder 内的几何/语义注入，
  两者在计算图位置和信号类型上完全正交。
