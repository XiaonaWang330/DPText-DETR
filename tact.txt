TACT: Topology-Aware Curvature Transform
========================================
纯视觉几何模块，在每个 decoder 层注入，解决小文本特征塌缩和尺度自适应问题。
零 CLIP / 零多模态依赖 — 只用控制点坐标做拓扑推理。


TACT 三个子机制:
─────────────────
① Gaussian Topology Aggregation
   → 基于控制点欧式距离的高斯邻居特征加权聚合
   → 小文本点距小 → 高斯核窄 → 防止特征过平滑
   → 大文本点距大 → 高斯核宽 → 保持邻域通信

② Curvature-Aware Residual Gating (Perona-Malik 各向异性扩散)
   → 高曲率角点 → modulation≈0 → 抑制残差 → 保 Precision
   → 低曲率平坦段 → modulation≈1 → 全量残差 → 提 Recall
   → kappa_gate 零初始化 → 训练第一步 = 无门控（安全渐变）

③ FiLM Circonv Modulation
   → 尺度因子 σ 通过仿射变换调制 circonv 环形卷积输出
   → γ, β 零初始化 → 训练第一步 = 原版 circonv
   → 大/小文本自动调节环卷积感受野强度

TACT 内部结构
═══════════════════════════════════════════════════════════════

输入: h_intra (B, N, 16, 256)   +   ref_points (B, N, 16, 2)
      │                                  │
      │                                  │
      ▼                                  │
  ┌──────────────────────┐               │
  │ [1] Sigma 预测        │               │
  │  h_inst = mean(h, dim=2)            │
  │  sigma = MLP(256→128→1→sigmoid)     │
  │  effective_sigma = base_sigma *     │
  │                     (1.0 + sigma)   │
  │               ∈ [0.1, 0.2]          │
  └─────────┬────────────┘               │
            │                            │
            ▼                            │
  ┌──────────────────────┐               ▼
  │ [2] 高斯权重矩阵      │   calc dist²(i,j) from ref_points
  │  w[i,j] = exp(-dist² / 2σ²)         │
  │  → 去对角线, 行归一化 →              │
  │  → (B,N,16,16)        │─────────────┘
  └─────────┬────────────┘
            │
            ▼
  ┌──────────────────────┐
  │ [3] 高斯邻居聚合      │
  │  neighbor_feat[i] =   │
  │    Σⱼ w[i,j] * h[j]   │
  │  → gauss_proj (zero init)          │
  │  → gauss_feat (B,N,16,256)         │
  └─────────┬────────────┘
            │
            ▼  ┌────────────────────────────────┐
  ┌──────────────────────┐                     │
  │ [4] CURA 曲率门控     │   ref_points        │
  │  curvature[i] =       │     │               │
  │   ||p[i-1]+p[i+1]-    │  ┌──┘               │
  │      2*p[i]||          │  │                  │
  │  modulation[i] =       │  │  环形邻点采样     │
  │   exp(-κ·curvature[i])  │  │  prev = roll(1)  │
  │  → gauss_feat *= mod   │  │  next = roll(-1) │
  └─────────┬────────────┘  │  │                  │
            │               ▼  ▼                  │
            │  curvature = ||prev+next-2*p||     │
            │  modulation = exp(-kappa_gate * κ) │
            │                                    │
            ▼  ┌────────────────────────────────┘
  ┌──────────────────┐    ┌──────────────────┐
  │ gauss_feat        │    │ film_scale        │
  │ (B,N,16,256)      │    │ (B,N,1)           │
  │ → 注入 intra-SA   │    │ → 调制 circonv    │
  └──────────────────┘    └──────────────────┘


═══════════════════════════════════════════════════════════════
曲率门控的物理直觉
═══════════════════════════════════════════════════════════════

控制点序列: p₀ ── p₁ ── p₂ ── p₃ ── ... ── p₁₅ (环形闭合)

  平坦段:                   角点:
  p₁   p₂   p₃              p_{i-1}
   ●───●───●                  ●
                               \
                                ● pᵢ  ← 曲率大
                               /
                              ● p_{i+1}

  p₁ + p₃ ≈ 2p₂          p_{i-1}+p_{i+1} ≠ 2pᵢ
  κ ≈ 0                  κ 大

  → modulation ≈ 1.0     → modulation ≈ 0
  → 全量聚合 → R↑         → 抑制聚合 → P↑

  kappa_gate 初始值 = 0
  → 初期 modulation = 1 (全量聚合)
  → 训练中 kappa_gate 逐渐增大 → 逐渐开始区分平坦/弯曲

═══════════════════════════════════════════════════════════════
与 Baseline 的关键差异
═══════════════════════════════════════════════════════════════

                         Baseline          +TACT
─────────────────────────────────────────────────────────
  Decoder 注入点           无              intra-SA 后 + circonv 后
  控制点间通信          仅 intra-SA         + 高斯距离加权聚合
  角点处理              无特殊处理          曲率门控抑制
  尺度感知              无                  σ 自适应 + FiLM
  新增参数              -                  ~100K (67% zero-init)
  训练安全性            -                  第一步 = baseline 严格等价
  CLIP 依赖             无                  无

  信号来源: 纯控制点坐标 (几何信号)
  注入方式: 残差注入 (gauss_feat 加到 h_sa)
  调制方式: FiLM (h_circonv * (1+γ) + β)
  零初始化: 保证训练连续性，不对 baseline 产生突变


═══════════════════════════════════════════════════════════════
设计原则
═══════════════════════════════════════════════════════════════

1. 零初始化 — 所有新增参数初始值为 0
   → gauss_proj, film_gamma/beta, kappa_gate = 0
   → 训练第一步 TACT 输出 = 0，等价 baseline
   → 梯度从 0 开始"学习激活"这些参数

2. 残差注入 — 不修改原有数据流
   → h_sa += gauss_feat (加性残差，不替换)
   → h_circonv = FiLM(circonv) (仿射调制，不替换)

3. 纯几何信号 — 不依赖任何外部模态
   → 只用控制点坐标 (ref_points) 做距离/曲率计算
   → 零 CLIP / 零文本 / 零多模态依赖
   → 可作为独立模块或与语言模块组合

4. 参数共享 — 6 层 Decoder 共用同一个 TACT
   → 参数量不乘 6，保持轻量
   → 学习的是跨层通用的拓扑变换模式

5. 保守带宽 — base_sigma=0.1, sigma∈[0,1]
   → effective_sigma ∈ [0.1, 0.2]
   → 高斯核窄，防止远距离点错误聚合
